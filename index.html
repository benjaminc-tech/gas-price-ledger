How this works
  • Each week, prices from the EIA are written to the contract by its owner's wallet. Writing costs a small fee ("gas") in test ETH.
  • Anyone can read the contract for free. This page sends eth_call requests to a public Sepolia node and decodes the answers itself, with no server and no libraries.
  • Nothing on-chain can be edited. If EIA corrects a price, the correction is added as a new revision.
  • This runs on a test network: the coins have no value.
