# Gas Price Ledger

Weekly US gasoline prices from the U.S. Energy Information Administration, recorded in a
smart contract on the Ethereum Sepolia test network. The page reads every number live
from the chain in your browser, with no server and no libraries.

Contract: [0xca8A40f3Bd33BDf35218A3399f75e70b38d3Cf20](https://sepolia.etherscan.io/address/0xca8A40f3Bd33BDf35218A3399f75e70b38d3Cf20#events)
